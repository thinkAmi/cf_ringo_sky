# 系譜は名前の分かる交配親を、打ち切り条件に当たるまで遡って登録する

品種に系譜を登録するとき、親が品種マスタに未登録だと参照整合の lint で落ちるため親も登録する必要があるが、どこまで遡るかの基準がなかった。10品種の一括登録（レッドキュー・江刺ロマンほか）で、紅ロマン → さんさ → ガラ・あかね → 海外品種と祖先の連鎖が続く事例が生じたため、基準を次のとおり定める。**名前の分かる交配親は行を作って系譜に載せ、さらにその親へと遡る。遡りを止めるのは、親が次のいずれかに当たったときだけとし、その親は unknown にして実際の記述を出典欄に注記する。**

1. **親が不明** — 偶発実生、オープン交配（自然交雑）など、出典が親を記載していない
2. **名前のない育成系統** — 例: 錦秋の花粉親 4-4349（つがる×いわかみ）、幸寿の花粉親（千秋×ふじ）。系統名や番号では今後同じものが投稿・参照される見込みがないため、行は作らない
3. **信頼できる出典で交配を確認できない** — 出典間で説が食い違う（例: コックスオレンジピピンの Ribston Pippin 説と DNA 解析による Margil 説）、推定の記述しかない（例: ロマンのしずくの「片親はトキと思われる」）、民間の販売サイトにしか記述がない（例: 御所川原の花粉親プリトニア）

打ち切った品種は、両親とも unknown なら基本品種になる。片親だけ分かる場合は、分かる側だけを埋める（例: 伊達ロマン = 紅ロマン × unknown）。

## Considered Options

- **(a) 依頼品種の直接の親までを登録し、祖父母以上は unknown にする** — 登録件数を抑えられるが、交配が分かっている祖先（さんさ = ガラ × あかね）まで基本品種として扱うことになり、「分かっているなら記載したい」という要求に合わない
- **(b) 世代数の上限を設ける** — 件数は予測しやすくなるが、上限の値に根拠がなく、上限の直下で交配が分かっていても切り捨てることになる
- **(c) 打ち切り条件に当たるまで遡る（採用）** — 系譜図で祖先を最大限たどれる。代償として、1品種の登録で祖先の行が数件増えることがある（さんさの系譜のために祖先が6行増えた）。海外の古い品種も対象になる

## Consequences

- 系譜を登録する作業では、親だけでなく祖先の連鎖を出典付きで調べることになる。register-apple-variety スキルの前提チェックはこの基準に従う
- 出典が食い違う親は条件3で打ち切るため、「1品種 = 1系譜」（ADR 0003）を保ったまま、異説は出典欄の注記として残る
- 祖先として登録した品種は、投稿されない限り集計グラフには現れない。表示名は、将来投稿するときの表記として既存行の慣例（カタカナ複合名は中黒なし）に合わせる
- この基準は今後の登録に適用する。既存の基本品種や unknown を含む系譜を一括で遡り直すことはしない。遡り直す場合は個別の訂正として扱う
